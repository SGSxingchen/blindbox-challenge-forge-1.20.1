# P4 交互、传送与在线音频准备记录

> 本文件只沉淀 P3 验收等待期间已经完成的只读设计结论，不代表 P4 已开工或已验收。P3 必须同一 SHA 六门禁全绿、归档并关闭 Issue #3 后，才创建 P4 工单和实施/验收矩阵。

## 固定范围

P4 交付信件、038 死亡笔记、037-B 任意门与 CORE-04 安全落点、046-D 发条小黄鸡，以及 047-B 木质手工八音盒的在线 OGG/MP3 播放。027 头戴式耳机仍只播放原版音乐；TAC、魔女服和乐魂继续不做。

## 已裁决的最小玩法

* **信件**：普通右键只读；潜行右键进入服务端会话控制的编辑菜单。正文只接受受限纯文本，服务端核验会话、手持槽位、实例 UUID、修订号、512 Unicode 码点和 16 行默认上限。
* **死亡笔记**：服务端只按在线玩家名解析目标，使用物品时建立受限会话；延迟和伤害取服务器配置，到期重新核验目标仍在线后执行。不得拼接或执行命令。
* **任意门**：潜行右键第一扇门选中，潜行右键第二扇门完成双向配对；走入门体才请求传送。目的门必须有独立的安全落点 `BlockItem`，并在服务端验证关联反链、目标维度/区块已加载、落点碰撞安全和两门不自指。任一条件不满足即拒绝，不强加载区块、不猜测落点。
* **发条小黄鸡**：服务端右键启动 60 秒默认倒计时，实体持久保存启动刻和主人等必要数据；时间到在实体当前位置按原版 TNT 语义爆炸，默认强度 8。断线、重启和区块卸载后不得重复或丢失结算。
* **八音盒在线音频**：仅配置/接受安全 `https` URL，服务端只保存、校验和向触发时**当前在线全服玩家**广播一次播放事件，客户端异步下载、缓存、解码和播放。禁止服务端下载/转发音频，禁止 Cookie、认证信息和私网/重定向绕过。支持 OGG 与 MP3；MP3 必须是许可证兼容的纯客户端解码实现，专服不得加载客户端音频类。新登录玩家不补播已经开始的事件。

## 实施与探针基线

P4 开工后按可独立回归的合理批次实现：先信件与死亡笔记的菜单/会话校验，再任意门与安全落点，再小黄鸡，最后八音盒在线音频。每批同时交付注册、原创可运行资源、简体中文/英语文本、专服隔离和独立 ciTest 业务探针；探针只放入 `src/ciTest` 与独立 Jar。

|对象|最低真实断言|
|---|---|
|信件|真实右键读取、潜行编辑、换手/修订冲突/越限文本拒绝，重连后 NBT 一致|
|死亡笔记|真实菜单提交、离线/改名/换手拒绝，延迟后仅原解析在线目标被服务端伤害|
|任意门|两门配对与反链、跨维安全落点、未加载/无安全点/碰撞/损坏关联全部拒绝|
|小黄鸡|真实倒计时、保存后重启、恰一次原版爆炸和实体/物品账本|
|八音盒|真实菜单配置、URL 安全拒绝、当时两客户端收到同一事件；OGG/MP3 客户端路径、缓存失败与新登录不补播|

所有 P4 完整验收仍须取得同一 SHA 的质量与构建、专服、强杀恢复、单客户端、双客户端和强制回归汇总六门禁。在线音频还必须明确真实未覆盖的第三方 URL 可用性、网络带宽和授权边界，不能以伪造成功 marker 代替客户端解码结果。
