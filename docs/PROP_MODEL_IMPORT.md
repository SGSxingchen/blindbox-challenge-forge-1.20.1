# 道具人工模型导入交付记录

本批次将用户提供的 `道具.zip` 作为只读人工设计输入，映射到既有九项盲盒道具；不新增物品 ID，不改变交互、伤害、投掷、放置、碰撞或存档业务。

|人工模型|正式资源映射|接入方式|
|---|---|---|
|三角锥|`road_barrier_helmet`|GeckoLib 头盔与物品 Geo 渲染|
|任意门|`anywhere_door`|原生静态方块模型|
|八音盒|`music_box`|GeckoLib 方块与物品 Geo 渲染|
|奖杯|`neutral_trophy`|原生静态方块模型|
|奶龙|`floor_art_panel`|采用人工几何构图，发行贴图保持项目原创|
|应援棒|`bml_cheer_stick`|原生开关、落地与墙面状态模型|
|白色人偶|`abstract_white_figurine`|原生静态方块模型|
|石墩子|`stone_pillow`|原生静态方块模型|
|钻石|`diamond_pillow`|原生加厚静态方块模型|

## 依赖、授权与确定性边界

复杂旋转和穿戴模型以 GeckoLib `4.8.4` 为强制前置。用户明确说明模型为人工制作并应导入，又提供转换后的八音盒与三角锥 Geo JSON，授权本项目使用、修改与发行；授权不外推给项目外第三方。两个 Geo、两个动画 JSON 和配套 PNG 已进入正式资源与 SHA-256 清单。人工确认后的八音盒、交通锥贴图固化在确定性生成器载荷中，不得回滚成旧占位图。

正式资源共 **186** 项，其中 PNG 仍为 **68** 张；新增的是 2 个 Geo JSON 和 2 个动画 JSON。压缩包内约 30 MiB 的应援棒广告图未进入正式资源、生成器或发行包，第三方形象和来源不明贴图也未复制。

## 本地验证边界

按用户要求，本批次暂停 GitHub Actions、PR、tag 和 Release，只运行本地生成器、资源契约、单元测试与 Gradle 构建。静态检查和构建只能证明资源引用、依赖、编译与打包闭合；真实客户端中的背包、手持、掉落、穿戴、放置、动画、尺度和方向仍须由本地客户端逐项观察，不能由静态测试冒充视觉验收。
