## 范围与排除

P2 只覆盖可按原版或受控轻交互语义验收的基础物品族。TAC 玩具 AK、魔女服装、黄金沙鹰与乐魂继续排除；变形、永久能力、投掷实体归 P3；GUI、任意门和在线音频归 P4。所有贴图均为原创抽象像素资源，不提交原始照片、压缩素材或成品截图。

## 强制门禁

动态 Gradle、Forge 与 Minecraft 仅在 GitHub Hosted Runner 执行。本阶段每一实质批次均须在同一提交通过：

|门禁|验收要求|状态|
|---|---|---|
|质量与构建|编译、检查、正式 Jar 与隔离 ciTest Jar；正式 Jar 不含探针|进行中|
|真实专用服务器|加载正式模组、启动、命令与正常停止|进行中|
|生命周期强杀恢复|`save-all flush → SIGKILL → 同世界重启`，保持 P1 资产守恒基线|进行中|
|真实单客户端|Xvfb 启动 Forge 客户端并稳定进入主菜单|进行中|
|真实双客户端|两独立客户端同服；P1 资产守恒与 P2 服务端业务探针均成功|进行中|
|强制回归汇总|同一 SHA 的五项必需工作流均成功；缺失、取消、跳过或失败均失败|进行中|

探针只能打入独立 `ciTest` Jar，必须从真实服务端状态断言，且不能破坏 P1 canonical 资产。禁止 `continue-on-error`、预写通过标志、删失败场景或将编译成功冒充行为覆盖。
