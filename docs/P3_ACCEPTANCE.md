|门禁|最低要求|当前证据|
|---|---|---|
|质量与构建|编译、检查、正式 Jar 与独立 ciTest Jar；正式 Jar 不含探针；逐包方向断言正确|待首个 P3 提交|
|真实专用服务器|加载正式模组、启动、命令与正常停止|待首个 P3 提交|
|生命周期强杀恢复|`save-all flush → SIGKILL → 同世界重启`；P1/P2 基线与 P3 持久状态均正确|待首个 P3 提交|
|真实单客户端|Xvfb 启动 Forge 客户端并稳定进入主菜单|待首个 P3 提交|
|真实双客户端|两独立客户端同服；P1/P2 回归及 P3 服务端业务探针、真实观察标记均成功|待首个 P3 提交|
