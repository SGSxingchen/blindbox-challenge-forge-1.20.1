## 仍未交付的命名需求

当前正式注册表有 64 个 `Item`，以及 7 个命名玩法方块（另有荧光棒、应援棒各一个墙面技术伴生方块，共 9 个 `Block` 注册）。P5 必须新增以下三个**无额外玩法效果**的原创装饰方块及各自 `BlockItem`：

|编号|中性原创交付|最低技术交付|不能宣称的内容|
|---|---|---|---|
|010 小白人|不复刻参考角色的抽象白色小摆件|方块、`BlockItem`、方块状态、模型、战利品、双语、原创 PNG、专服/双端放置与回收探针|不得把黑白参考形象或照片直接作为贴图|
|036 地面画像|不复刻角色、商标或画作的原创风格化地面画板|同上；使用中性名称和原创图案|不得声称已取得角色、画作或包装授权|
|051 奖杯|不使用未知赛事名称、标志或文字的原创中性奖杯|同上；使用中性名称和原创轮廓|不得声称原赛事名称或奖杯造型已获授权|

三项完成后为 67 个 `Item`、10 个命名玩法方块；算上两个墙面技术伴生方块为 12 个实际 `Block` 注册。编号 012 没有名称、效果、图片或可验证玩法，且已在 P3 范围说明中排除；不能擅自编造物品补足计数。TAC 玩具 AK、魔女服、黄金沙鹰和乐魂继续按既定决定排除。

## 正式资源与模型

1. 为每个正式资源建立逐文件清单：路径、SHA-256、原创作者、仅保留的参考方向、许可证/署名、审核日期与中性替换方案。清单必须覆盖所有 `assets/blindboxchallenge` PNG、模型、方块状态和界面资源，而不是只记录少数抱枕或剪刀。
2. 完成资产矩阵中明确的人工精修审看：005 翅膀、033 路障头饰、045 剪刀、046-D 小黄鸡、抱枕坐姿/投掷、任意门开合、伏特加视觉。当前原版可运行外观或占位图不能写成已精修模型/动画。
3. 自动静态门禁至少检查：正式资源白名单、禁止 JPG/WEBP/PSD/压缩包/正式音频、PNG 签名与尺寸/无额外元数据、JSON/模型/纹理引用、注册—模型—中英文本三向闭合、双语键一致、资源清单覆盖与哈希固定、正式 Jar 排除 `ciTest`/`ci-audio`。

当前逐文件 SHA-256 清单已落盘到 [正式资源审计清单](ASSET_MANIFEST.md)。其中 68 张 PNG 标为项目内原创重绘：原版图片仅作需求输入且不进入 Release；其余正式资源标为项目方提供并许可本项目使用、修改与发行，不外推对项目外第三方的再授权。

## 八音盒压力与发行证据

* 在 Hosted Runner 增加受控的多 URL 真实 GUI → 下载 → PCM 场景，验证 64 MiB LRU 驱逐、被驱逐后重新下载、同 URL 单飞、损坏缓存删除与重试。测试音频只放独立 `ciTest` Jar，不能用预写 marker 或生产内置音频替代。
* 统一正式语义版本，移除当前 `0.1.0-p1` 的开发标记；更新根 README 与 `mod/README.md` 的安装、专服、客户端、八音盒 HTTPS/一次播放限制、JLayer LGPL 和真实边界说明。
* 只有最终同 SHA 六门禁全绿后，才生成正式 Jar/SHA-256、创建不可变 Git tag 和 GitHub Release，并发布中文使用说明、完整资产/许可证记录与未覆盖边界。

## 必须人工或外部裁决的边界

静态检查不能替代人工游戏审看模型比例、可读性、动画和眩晕舒适度。第三方 HTTPS 音频的持续可访问性、带宽、版权和长期地址稳定性不能写成发行承诺；本项目不外推对项目外第三方的再授权。
