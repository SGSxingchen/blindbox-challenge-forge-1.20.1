## 运行边界

* 八音盒只允许 HTTPS URL；仅向触发时在线的玩家广播一次，不给后来登录者补播。客户端异步下载、严格校验、解码和缓存，服务端不代理音频。
* P5 真实双端场景覆盖 64 MiB 缓存的 LRU 驱逐重下、单进程单飞与损坏缓存重试；不承诺任意第三方音频、长期地址、带宽或跨进程共用缓存。
* JLayer 依赖随正式候选保留 LGPL-2.1 与 NOTICE；公开发行前仍须完成项目整体许可证兼容性审查。
* 已知恢复边界包括：未 `save-all flush` 的掉电窗口、死亡笔记到期伤害前后的非原子窗口，以及未加载伙伴门/任意拓扑恢复；详细边界见各阶段验收文档。
* TAC、魔女服、乐魂、原始照片和压缩素材不在范围内。
