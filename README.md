# 盲盒挑战生存（Forge 1.20.1）
## 版本与范围

当前工作树为 **1.0.5 修正候选，尚未发布**，以九组人工模型导入代码为基础恢复原物品名称，并修正效果和交互。当前批次按根目录阶段说明只做本地验证，远程构建与发布继续暂停；历史验收不能替代本批次的实际游戏验证。修正范围、配置和未完成项见 [物品修正记录](docs/ITEM_CORRECTIONS_2026-10-03.html)，完整变更见 [更新日志](CHANGELOG.md)。

全部 189 项正式资源由项目内重绘、用户授权人工模型或定义产物组成：74 张 PNG 中有 71 张由生成器可复现重建，另外 3 张为既有人工模型配套贴图，另含两个模型几何文件和两个动画文件；其余模型、方块状态、战利品、双语与元数据由项目内定义生成器闭合。文绪立牌和奶龙老鼠干按用户在本轮提供的外观图片重新绘制，其余重绘延续原有文字需求输入；参考图片本身不进入发行包。项目方提供素材与需求背景，许可本项目使用、修改与发行；该许可不外推给项目外第三方。逐文件记录见 [资源审计清单](docs/ASSET_MANIFEST.md)。

## 安装与校验

运行环境：**Java 17、Minecraft 1.20.1、Forge 47.4.22**。

1. 历史正式版在 [发布页](https://github.com/SGSxingchen/blindbox-challenge-forge-1.20.1/releases) 下载；选择同一版本的 `blindboxchallenge-版本号-all.jar` 与其 SHA-256 文件。此工作树的修正尚未进入发布页。
2. 在下载目录执行 `sha256sum -c 对应文件名.jar.sha256`；结果必须为 `OK`。
3. 客户端将该 `-all.jar` 放进实例的 `mods/`；专用服务器将同一文件放进服务器的 `mods/`，再按 Forge 常规方式启动。
4. **绝不能安装或分发 `*-citest.jar`**：它只含 GitHub Hosted Runner 的探针和音频夹具，不是游戏模组。

本工作树的完整包携带模型库和音频解码库，并保留相应许可文本；不要用不含 `-all` 的普通开发 Jar 替代完整包。

## 创造模式物品栏

创建世界或在服务器中取得创造模式后，打开原版创造模式物品栏，切换到 **“盲盒挑战 / Blind Box Challenge”** 标签页即可获得全部 67 项正常玩家物品。标签顺序由实际注册顺序统一维护；盲盒、信件、死亡笔记仍在正常服务端交互时写入受控数据，门默认未联结、八音盒默认未配置、浴桶默认空。

`glow_stick_wall`、`bml_cheer_stick_wall` 是两种放置物的墙面技术状态，不是独立物品；实体、方块实体和菜单同样不提供伪造的创造栏条目。

## 使用边界

* 八音盒只接受 HTTPS URL，只向触发时在线的玩家发送一次播放事件；后来登录者不会补播，服务器不代理音频。
* 缓存验证覆盖单个游戏进程/目录内的 64 MiB LRU、驱逐重下、同 URL 单飞与损坏缓存重试；不承诺任意第三方 URL 的可用性、带宽、版权或长期稳定性。
* 如实保留的恢复边界：未 `save-all flush` 的掉电窗口、死亡笔记到期伤害前后的非原子窗口、未加载伙伴门和任意门拓扑恢复。
* TAC、魔女服、乐魂、原始照片与压缩素材不在当前范围，也不进入 Release。
