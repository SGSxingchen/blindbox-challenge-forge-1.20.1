# 盲盒挑战生存 Forge 模组
当前工作树为 **1.0.5 修正候选，尚未发布**，运行环境为 Java 17、Minecraft 1.20.1、Forge 47.4.22。客户端和专用服务器均使用相同版本的完整 `-all.jar`，历史发布页中的包尚不含本批修正。

`src/ciTest` 与 `*-citest.jar` 是隔离验收探针和受控音频夹具，绝不能安装、分发或混入正式包。当前按根目录阶段说明做本地验证，远程构建与发布仍暂停；编译和静态通过不能替代实际游戏验证。

八音盒只接受 HTTPS URL，并仅对触发当时在线的玩家一次播放；缓存压力只证明受控 URL 和单进程缓存语义。创造模式中可在“盲盒挑战 / Blind Box Challenge”标签页获得全部 67 项正常玩家物品；两种墙面附属方块、实体、方块实体和菜单不伪造条目。全部 186 项正式资源由项目内重绘、用户授权人工模型或定义产物组成，其中文绪立牌和奶龙老鼠干依据本轮用户图片重新绘制，参考图片本身不进入发行包；项目方提供素材与需求背景并许可本项目使用、修改与发行，不外推对项目外第三方的授权。完整安装说明、验收和真实边界见仓库根目录 [README](../README.md)、[创造栏补丁记录](../docs/V1_0_1_CREATIVE_TAB.md) 与 [更新日志](../CHANGELOG.md)。
